# Fixtures privées

Contenu de ce dossier gitignoré, à l'exception de ce README.

Y placer les documents réels utilisés comme fixtures (rapports, comptes rendus,
emails exportés, révisions de documents), organisés par cas :

```
private/
└── <case_id>/
    ├── case.json
    ├── ground-truth.json
    └── texts/…
```

Ces fichiers ne quittent jamais la machine sur laquelle ils sont déposés.
